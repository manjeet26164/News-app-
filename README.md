# News App 📰

A dynamic web application that aggregates real-time news articles from various global sources. This project utilizes the **NewsAPI** to provide users with the latest headlines, categorized updates, and search functionality in a clean, responsive interface.

## 🚀 Features

* **Live Headlines:** Fetches the latest breaking news from top sources around the world.
* **Category Filtering:** Browse news by specific categories such as Business, Technology, Entertainment, Health, Science, and Sports.
* **Search Functionality:** Search for specific topics or keywords to find relevant articles instantly.
* **Direct Links:** Click on any news card to read the full article on the original source website.
* **Responsive Design:** Optimized layout that works seamlessly on desktops, tablets, and mobile phones.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API:** [NewsAPI.org](https://newsapi.org/) (JSON data fetching)
